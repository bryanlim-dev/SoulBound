## Generation
## --------------------------
To generate the solution files, run program run.bat.
CMake of minimum v3.30.3 is required, if it does not exist within the system, 
run.bat will download and unzip a local copy to use, then deletes it.
After running the program, it will generation the solution files within the build folder.



## Clean Up
## --------------------------
To clean up the files, run program clean.bat.
It will delete all generated files and delete the local CMake folder if it exists



## Downloading CMake manually
## --------------------------
If there is a need to download CMake on the system, do the following steps

1. Download CMake file from the following link
https://github.com/Kitware/CMake/releases/download/v3.30.3/cmake-3.30.3-windows-x86_64.msi
2. Run cmake-3.30.3-windows-x86_64.msi from downloads folder
3. Follow the instructions on the new window and install CMake



## Manual CMake Generation
## --------------------------
1. Create a new folder "build" inside "NightSnack Engine/". (same level as this README file)
2. Open CMD inside "build" folder.
3. Type "cmake .." (Do this in plain CMD, not WSL)

You should now be able to find "NightSnack.sln" inside the "build" folder.

After opening the sln, on the top row of button select Project > Property,
change the option within "Single startup project" to "Game".
The solution should be ready to build.
