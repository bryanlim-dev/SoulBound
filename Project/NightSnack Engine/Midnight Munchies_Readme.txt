## Debug Controls
## --------------------------
O: Activate debug-drawing
F1: Display FPS
F2: Default Dialogue display
Escape: Toggle Pausing Game Scene


## Player Controls
## --------------------------
A Key: Moves player left
D Key: Moves player right
Spacebar Key: Player jump / ability

W Key: Move up when Frog Tongue is attached to ceiling
S Key: Move down when Frog Tongue is attached to ceiling

J Key: Possess/Unpossess statue monsters

Abilities: 
Hold Spacebar Key(when in air): Ghost|Glide, HellFrog|Tongue, 
Spacebar Key(when in air): FlyEye|Extra Jump


## Step by Step Physics debug
## --------------------------
Ctrl + P: Toggle Step by Step Module
P: When enabled, Step to next frame
